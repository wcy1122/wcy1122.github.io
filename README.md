# wcy1122.github.io

Personal academic homepage for Chengyao Wang. Plain HTML, CSS, and JavaScript; no build step is required.

- `index.html`: biography, news, publications, awards, and academic service.
- `styles.css`: responsive layout and light/dark themes.
- `utils.js`: theme preference and news expansion. All content remains readable without JavaScript.

Preview locally with `python3 -m http.server 8765 --bind 127.0.0.1`.

Visual direction inspired by [Rulin Shao's homepage](https://rulinshao.github.io/); implementation written for this site.
